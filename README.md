# Task-6-Algorithms-and-data-structure

Решения алгоритмических задач с использованием бинарного поиска, жадных алгоритмов и хеш-структур. Включает реализацию на Python, тесты (pytest) и пояснения (а так же красивая печать для второго задания в main) <3

## Задачи

### 1. Наибольшая непрерывная возрастающая последовательность

Дан массив не отсортированных чисел. Необходимо найти максимально длинную непрерывную возрастающую последовательность и вернуть её длину.

**Примеры:**
- `[3, 2, 8, 9, 5, 10] → 3`
- `[1, 2, 7, 9, 0, 10] → 4`
- `[8, 8, 8, 8] → 1`

**Что нужно сделать:**
- Реализовать решение за O(n)
- Использовать один проход по массиву
- Объяснить, как отслеживаются текущая и максимальная длины последовательности

---

### 2. Треугольник Паскаля

Дано число `n`. Необходимо построить треугольник Паскаля из `n` строк.

**Что нужно сделать:**
- Реализовать построение треугольника
- Пояснить, как каждая строка формируется из предыдущей
- Объяснить сложность алгоритма O(n²)

---

### 3. Размен монет

Дан массив номиналов монет `coins` и число `amount`.  
Необходимо найти минимальное количество монет, составляющих сумму `amount`, либо вернуть `-1`, если это невозможно.

**Что нужно сделать:**
- Реализовать решение с использованием динамического программирования
- Использовать одномерный массив `dp`
- Объяснить переход: `dp[i] = min(dp[i], dp[i - coin] + 1)`
- Обосновать корректность решения

---

### 4. Максимальный палиндром в строке

Дана строка `s`. Необходимо найти её самую длинную подстроку-палиндром.

**Что нужно сделать:**
- Реализовать алгоритм расширения от центра
- Рассмотреть случай чётных и нечётных палиндромов
- Объяснить сложность O(n²)
- (Дополнительно) рассмотреть подход через динамическое программирование
